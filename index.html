📋 就活管理アプリの使い方

  1. 右下の ＋ ボタンで、応募する企業を追加します。
  2. 選考ステータス（エントリー → 書類選考 → 面接 → 内定…）を選んで、今どの段階かを記録できます。
  3. 締め切り日を入れると「あと○日」が自動表示。締切が近い案件は画面上部に ⚠️ で知らせます。
  4. カードをタップすると、いつでも内容の編集・削除ができます。
  5. カードの 📅 カレンダーに追加 で、締切をGoogleカレンダーに登録できます。
  6. 上部のボタンで、ステータス別の絞り込みや並び替え（締切順・志望度順）ができます。
💡 入力したデータは、この端末の中に自動で保存されます。閉じても消えません。

⚙️ クラウド同期の設定

普段はオフラインで使え、ボタンを押したときだけ同期します。下のヘルプの手順でFirebaseを準備してください。

⚠️ このコードは合言葉です。他人に教えず、別の端末では同じコードを入力してください。

📖 Firebaseの準備手順（初回のみ・無料）
  1. Firebase Console をGoogleアカウントで開き「プロジェクトを追加」
  2. 左メニュー「構築 → Firestore Database」でデータベースを作成（リージョンは asia-northeast1 など）。最初はテストモードでOK
  3. 「ルール」タブを開き、下記を貼り付けて公開： 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /boards/{code} {
      allow read, write: if code.size() >= 16;
    }
  }
}
  4. プロジェクト設定（⚙️）→「マイアプリ」でウェブアプリ </> を追加すると const firebaseConfig = {...} が表示される
  5. その firebaseConfig を上の欄に貼り付け → 「生成」で同期コードを作成 → 保存して接続
  6. 別の端末では、同じ firebaseConfig と同じ同期コードを入力すれば同期できます
