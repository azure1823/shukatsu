# 📋 就活管理アプリ

就職活動の **選考ステータス** と **締め切り** を一目で管理できる、シンプルなWebアプリです。
ファイル1つ（`index.html`）で動き、インストール不要・スマホ対応・データは端末内に自動保存されます。

---

## ✨ 主な機能

| 機能 | 内容 |
|---|---|
| 🎯 選考ステータス管理 | エントリー → 書類選考(ES) → 適性検査 → 一次 → 二次 → 最終 → 内定 / お祈り の8段階を色分け表示 |
| 📅 締め切り管理 | 締切日ごとに「あと○日」を自動計算。**締切が近い順**に並び替え。当日・超過は赤、3日以内は黄色で強調 |
| ⚠️ 画面リマインド | 締切が3日以内の案件を画面上部に警告表示 |
| 🏢 企業メモ | 志望度（★5段階）・職種・企業ページURL・自由メモ |
| 🔍 絞り込み / 並び替え | ステータス別フィルタ、締切順・志望度順・企業名順 |
| 💾 バックアップ | データをJSONで書き出し / 復元 |
| ☁️ クラウド同期 | （任意）Firebase連携で、PC・スマホ間を手動同期 |

---

## 🚀 使い方

### すぐ使う（オフライン）
`index.html` を **ダブルクリック** するだけで起動します。ネット接続もインストールも不要です。

- 右下の **＋** ボタンから企業を追加
- カードをタップで編集・削除
- データはブラウザ内（localStorage）に自動保存されます

---

## ☁️ クラウド同期の設定（任意）

普段はオフラインで動き、**ボタンを押したときだけ**端末間でデータを同期できます（Firebaseを使用・無料枠で十分）。

### 準備（初回のみ）
1. [Firebase Console](https://console.firebase.google.com) でプロジェクトを作成（Googleアカウントで無料）
2. **Firestore Database** を作成（テストモードでOK、リージョンは `asia-northeast1` など）
3. 「ルール」タブに以下を貼り付けて公開：
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /boards/{code} {
         allow read, write: if code.size() >= 16;
       }
     }
   }
   ```
4. プロジェクト設定 → マイアプリ → **ウェブアプリ `</>`** を追加し、表示される `firebaseConfig` をコピー
5. アプリ内の **⚙️ クラウド設定** に貼り付け → 「生成」で同期コードを作成 → **保存して接続**

### 同期する
- **☁️↑ アップロード**：この端末のデータをクラウドへ保存
- **☁️↓ ダウンロード**：クラウドのデータをこの端末へ取得
- 別の端末では、**同じ `firebaseConfig` と同じ同期コード**を入力すれば同期できます

> 💡 同期コードは合言葉です。他人に教えないでください。
> 💡 Firebaseは無料プラン（Spark）のままならカード未登録で、請求は発生しません（上限を超えると停止するだけ）。

---

## 🔒 プライバシー

- アプリの **コードのみ** が公開され、入力した企業情報は公開されません
- データの保存先は **あなたの端末のブラウザ**、またはクラウド同期を使う場合は **あなた自身のFirebase** だけです

---

## 🛠 技術

- 単一HTMLファイル（HTML / CSS / Vanilla JavaScript）
- 依存ライブラリなし（クラウド同期時のみ Firebase SDK をCDNから読み込み）
- データ保存：localStorage ＋（任意）Cloud Firestore
